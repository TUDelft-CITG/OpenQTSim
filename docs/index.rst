Open source Queueing Theory Simulation
======================================

OpenQTSim is a python package for discrete event simulation of queues with a Kendall notation
(for example M/M/1, D/D/2, M/E2/n or E2/E2/n). It was developed for teaching queueing theory at TU Delft:
the example notebooks reproduce lecture examples, compare simulations with analytical solutions and
create waiting time tables with many parallel simulations (using Dask).

Welcome to OpenQTSim documentation! Please check the contents below for information on installation,
the example notebooks and the API. If you want to dive straight into the code you can check out our
`GitHub`_ page or the working examples presented in the `Jupyter Notebooks`_.
